Toutes les tables clés en une page — pour référence rapide en session

⚙️ Mécanique de base

1d20 + Carac + Compétence (+ Spécialité) vs DD

Caractéristique (0→+3) + Compétence plafonnée +3 (Novice +1 / Confirmé +2 / Expert +3). Ajoute +1 si une Spécialité colle au contexte. Magie : 1d20 + INT + Affinité. Sans compétence : 1d20 + Carac seul.

Le 1 et le 20 naturels sont toujours critiques, quel que soit le bonus ou le DD (façon Aventures).

Aide-mémoire DD (c'est le MJ qui fixe)

5Très facile — forcer une porte branlante, se souvenir d'une rumeur courante
10Facile — escalader un mur bas, marchander un prix, pister en forêt
15Standard — convaincre un garde méfiant, déchiffrer un script simple, sauter un fossé large
20Difficile — désamorcer un noble hostile à la cour, crocheter une serrure de maître
25Très difficile — lire un Mot Primordial ancien, traverser un Nœud instable
30Héroïque — un exploit à la limite du possible

Calibrer sur le perso (reco) : DD ≈ 11 + son bonus = défi tendu (~55-60 %). −5 si tu le veux facile, +5 pour le mettre en danger. Ainsi chaque +1 compte toujours.

On ne lance pas si bonus ≥ DD−1 (réussite auto) ni si un 19 n'atteint pas le DD (impossible sans levier). Tu peux cacher le DD : le joueur annonce son total, tu donnes le résultat.

DD lus, pas choisis : attaque = Défense de la cible (10 + DEX + armure) ; artisanat/magie ont leurs propres tables.

⚡ Éther

Réserve max = 3 + INT + CON
  • Récup complète : nuit
  • Récup 50% : 1h repos
  • Surcharge : dépasser la réserve = −1 tous les jets / 24h par point
  • 5 surcharges : coma 3 jours

Renforcement physique

  • 1 Éther = +5 à un jet physique
  • 2 Éther = +5 dégâts

Même table que jets généraux : Arraché = touche mais dégâts min ; Pleine = normal ; Éclatante = +dégâts ; Coup d'éclat = critique

  • Désarmer : DEX vs FOR, arme tombe
  • Étouffer : FOR vs FOR, no action
