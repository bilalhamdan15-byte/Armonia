Générateur de tavernes V1 — Test

Trois tavernes générées à partir du vocabulaire extrait de Large Tavern & Inn. Chacune reprend les mêmes assets (sol, murs, toit) mais avec des dimensions et un layout différents.

⚠️ V1 test — Cette version utilise seulement 4 tiles structurels (sol + 2 murs + toit) et place quelques clusters de mobilier au RDC. Pas encore de portes, fenêtres, ni escaliers. C'est un premier test pour vérifier que le pipeline fonctionne bout-en-bout.

Comment tester dans TaleSpire

  1. Copie un des codes ci-dessous
  2. Dans TaleSpire, active le mode construction (touche B)
  3. Menu contextuel → Paste Slab from Clipboard (raccourci Ctrl+V dans le mode construction)
  4. Clique dans le monde pour placer la taverne
  5. Dis-moi ce qui va / ne va pas visuellement (murs à l'envers, trous, sols manquants…) — je corrige
