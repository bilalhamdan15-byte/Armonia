Townhouse — 4 variantes générées

Je peux maintenant lire n'importe quel slab (Large Tavern, Townhouse), le décoder, le manipuler et le ré-encoder avec mon format fixé.

Les 4 tests ci-dessous te prouvent :
  1. Round-trip pur : le townhouse à l'identique (test décodage/ré-encodage)
  2. RDC seul : uniquement le rez-de-chaussée (extraction d'étage)
  3. 2 étages : sans le grenier (troncature)
  4. Miroir X : la maison retournée horizontalement (transformation)
